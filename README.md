# Cyber Toolkit

En menustyret Python-værktøjskasse til cybersikkerhed, samlet i én fil: `wx7_v3.py`.

> **Kun til lovlig brug.** Brug kun værktøjet på systemer, du ejer eller har skriftlig tilladelse til at teste. Uautoriseret scanning eller angreb er ulovligt.

## Krav

- Python 3.9 eller nyere
- Linux eller macOS (anbefalet)

## Kør

```bash
python3 wx7_v3.py
```

Programmet viser en menu og beder om bekræftelse, før aktive handlinger udføres.

## Funktioner

- Menu-drevet terminal-interface med farver
- Samling af værktøjer til netværk, hashing, parsing og protokoller
- Indbygget advarselsbanner og bekræftelse
